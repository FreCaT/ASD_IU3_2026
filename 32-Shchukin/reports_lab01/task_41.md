## 1. Условие задачи

Получить массив, из которого удалены все вхождения заданного числа `x`.

**Ввод:** Число `n`, затем `n` целых чисел, затем `x`.  
**Вывод:** Все оставшиеся элементы в исходном порядке, разделённые пробелами; если не осталось ни одного — пустая строка.

## 2. Идея и реализация алгоритма

Основной метод: ``Task41.removeAll(int[] values, int target)``.

Первым проходом определяется число элементов, не равных `x` (`kept`). Создаётся новый массив длины `kept`. Во втором проходе туда последовательно копируются все элементы, отличные от `x`.

**Обоснование выбора метода:** Нельзя физически уменьшить размер обычного массива Java. Создание нового массива точной длины упрощает удаление всех совпадений, сохраняет исходный порядок и не требует сторонних коллекций.

## 3. Анализ асимптотики

- **Время:** **O(n)**: два последовательных прохода по исходному массиву.
- **Дополнительная память:** **O(n)** в худшем случае для нового массива; точнее **O(k)**, где `k` — количество оставшихся элементов.

Оценки относятся к вычислительному методу. Считывание входных данных через `InputReader` и их хранение в исходном массиве/матрице учитываются отдельно, если указаны выше.
