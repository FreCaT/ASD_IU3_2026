## 1. Условие задачи

По целочисленному массиву определить его минимальный и максимальный элементы.

**Ввод:** Число `n`, затем `n` целых чисел.  
**Вывод:** Два числа: минимум и максимум (именно в таком порядке).

## 2. Идея и реализация алгоритма

Основной метод: ``Task01.findMinMax(int[] values)``.

Первый элемент принимается одновременно за текущий минимум и максимум. Далее каждый элемент сравнивается с найденными значениями с помощью `Math.min` и `Math.max`. По окончании прохода метод возвращает массив из двух чисел.

**Обоснование выбора метода:** Для нахождения обоих экстремумов достаточно одного прохода; сортировка не нужна. Инициализация первым элементом корректна даже для массива, содержащего только отрицательные числа.

## 3. Анализ асимптотики

- **Время:** **O(n)**: цикл проходит через все `n` элементов один раз; на каждом шаге выполняется постоянное число сравнений.
- **Дополнительная память:** **O(1)** дополнительной памяти алгоритма: две переменные и массив результата длины 2.

Оценки относятся к вычислительному методу. Считывание входных данных через `InputReader` и их хранение в исходном массиве/матрице учитываются отдельно, если указаны выше.
