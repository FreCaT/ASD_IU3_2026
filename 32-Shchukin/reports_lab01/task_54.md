## 1. Условие задачи

Вычислить сумму элементов главной диагонали квадратной целочисленной матрицы.

**Ввод:** Число `n`, затем `n` строк по `n` целых чисел.  
**Вывод:** Одно целое число — сумма элементов `a[i][i]`.

## 2. Идея и реализация алгоритма

Основной метод: ``Task54.diagonalSum(int[][] matrix)``.

Для каждой строки с индексом `i` выбирается элемент `matrix[i][i]`, после чего он прибавляется к переменной `result` типа `long`.

**Обоснование выбора метода:** Главная диагональ состоит ровно из `n` элементов: от левого верхнего угла до правого нижнего. Проверять все `n²` ячеек не требуется.

## 3. Анализ асимптотики

- **Время:** **O(n)** для суммирования `n` диагональных элементов. При запуске `main()` чтение всей матрицы требует **O(n²)** времени.
- **Дополнительная память:** **O(1)** дополнительной памяти самого алгоритма; `main()` хранит входную матрицу и использует **O(n²)** памяти.

Оценки относятся к вычислительному методу. Считывание входных данных через `InputReader` и их хранение в исходном массиве/матрице учитываются отдельно, если указаны выше.
