## 1. Условие задачи

Подсчитать элементы, строго большие среднего арифметического. По условию среднее арифметическое целое.

**Ввод:** Число `n`, затем `n` целых чисел.  
**Вывод:** Одно число — количество значений строго больше среднего.

## 2. Идея и реализация алгоритма

Основной метод: ``Task06.countAboveAverage(int[] values)``.

Сначала вычисляется сумма всех элементов в переменной `long`, затем среднее `sum / values.length`. Вторым проходом считается число элементов, удовлетворяющих строгому неравенству `value > average`.

**Обоснование выбора метода:** Два прохода позволяют получить среднее, не сохраняя дополнительные значения. Целочисленное деление допустимо, поскольку в условии гарантировано, что сумма делится на `n` без остатка.

## 3. Анализ асимптотики

- **Время:** **O(n)**: один проход для суммы и один для подсчёта.
- **Дополнительная память:** **O(1)**: сумма, среднее и счётчик.

Оценки относятся к вычислительному методу. Считывание входных данных через `InputReader` и их хранение в исходном массиве/матрице учитываются отдельно, если указаны выше.
