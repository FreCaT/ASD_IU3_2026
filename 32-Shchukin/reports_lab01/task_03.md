## 1. Условие задачи

Найти количество элементов массива, равных заданному числу `x`.

**Ввод:** Число `n`, затем `n` целых чисел, затем `x`.  
**Вывод:** Одно число — количество совпадений.

## 2. Идея и реализация алгоритма

Основной метод: ``Task03.countOccurrences(int[] values, int target)``.

Начинаем со счётчика `count = 0`. Для каждого элемента увеличиваем счётчик на единицу, если он равен `target`. Возвращаем значение после полного прохода.

**Обоснование выбора метода:** Чтобы учесть все совпадения, нельзя завершать просмотр после первой находки. Счётчик не требует дополнительного массива.

## 3. Анализ асимптотики

- **Время:** **O(n)**: каждый элемент просматривается один раз.
- **Дополнительная память:** **O(1)**: один счётчик.

Оценки относятся к вычислительному методу. Считывание входных данных через `InputReader` и их хранение в исходном массиве/матрице учитываются отдельно, если указаны выше.
