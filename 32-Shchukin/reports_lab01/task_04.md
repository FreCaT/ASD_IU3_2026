## 1. Условие задачи

Найти все индексы элементов, равных `x`, и вывести их по возрастанию.

**Ввод:** Число `n`, затем `n` целых чисел, затем `x`.  
**Вывод:** Индексы совпадений, разделённые пробелами. При отсутствии совпадений выводится пустая строка.

## 2. Идея и реализация алгоритма

Основной метод: ``Task04.allIndices(int[] values, int target)``.

Первый проход подсчитывает количество совпадений `k`. Затем создаётся массив `indices` длины `k`. Во втором проходе в него записываются все подходящие индексы в порядке просмотра.

**Обоснование выбора метода:** Двухпроходный подход позволяет сразу выделить массив результата точного размера. Поскольку второй проход идёт слева направо, порядок индексов автоматически возрастает.

## 3. Анализ асимптотики

- **Время:** **O(n)**: не более двух последовательных проходов, то есть `2n` элементарных проверок.
- **Дополнительная память:** **O(k)** дополнительной памяти для массива индексов, где `0 ≤ k ≤ n`; в худшем случае **O(n)**.

Оценки относятся к вычислительному методу. Считывание входных данных через `InputReader` и их хранение в исходном массиве/матрице учитываются отдельно, если указаны выше.
