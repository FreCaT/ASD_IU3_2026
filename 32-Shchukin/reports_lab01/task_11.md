## 1. Условие задачи

Найти элемент массива, наиболее близкий к его среднему арифметическому. При равных расстояниях выбрать первый по индексу.

**Ввод:** Число `n`, затем `n` целых чисел.  
**Вывод:** Значение выбранного элемента массива.

## 2. Идея и реализация алгоритма

Основной метод: ``Task11.closestToAverage(int[] values)``.

Вычисляется сумма `S` элементов и длина `n`. Для каждого значения `a[i]` сравнивается величина `|a[i]·n − S|` вместо вещественного расстояния `|a[i] − S/n|`. При строго меньшем расстоянии запоминается текущий элемент.

**Обоснование выбора метода:** Умножение на одинаковое положительное `n` не меняет порядок расстояний; следовательно, можно сравнивать целые числа без ошибок округления `double`. Условие обновления строгое (`<`), поэтому при равенстве расстояний остаётся первый встретившийся элемент.

## 3. Анализ асимптотики

- **Время:** **O(n)**: один проход для суммы и один — для поиска лучшего значения.
- **Дополнительная память:** **O(1)**: хранится сумма, минимальное расстояние и выбранное значение.

Оценки относятся к вычислительному методу. Считывание входных данных через `InputReader` и их хранение в исходном массиве/матрице учитываются отдельно, если указаны выше.
