## 1. Условие задачи

Вычислить определитель целочисленной матрицы размера 3×3.

**Ввод:** Девять целых чисел — элементы трёх строк матрицы (размер фиксирован, отдельное `n` не читается).  
**Вывод:** Одно целое число — точный определитель матрицы.

## 2. Идея и реализация алгоритма

Основной метод: ``Task59.determinant(int[][] matrix)``.

Применяется разложение по первой строке: `det(A) = a(ei − fh) − b(di − fg) + c(dh − eg)`. Вспомогательный метод `minor` вычисляет разности произведений для миноров 2×2.

**Обоснование выбора метода:** Для фиксированной матрицы 3×3 разложение по первой строке требует постоянного числа операций и не нуждается в сторонних алгоритмах. `java.math.BigInteger` — стандартный класс JDK — используется, чтобы не переполнить `long` при произведении больших значений `int`.

## 3. Анализ асимптотики

- **Время:** **O(1)** при условии фиксированного размера 3×3 и входных значений `int`: число арифметических действий постоянно.
- **Дополнительная память:** **O(1)**: фиксированное число временных объектов и результат ограниченной разрядности для трёх 32-битных множителей.

Оценки относятся к вычислительному методу. Считывание входных данных через `InputReader` и их хранение в исходном массиве/матрице учитываются отдельно, если указаны выше.
